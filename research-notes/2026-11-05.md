### A Hybrid Approach for Automated Security Pattern Recovery

- Source: arXiv CS.AI
- Published: 2026-11-05
- Link: https://arxiv.org/abs/2611.05823
- Matched layers: market_context

We present SecPatRec, a hybrid approach for automated security pattern recovery from source code repositories. We treat a security pattern as a reference architecture and frame its recovery as a deductive task: determining which prescribed roles are present, grounding them in code entities, and recovering their interaction sequences.

### Agent Gym: A Framework for Continuous Evaluation and Evolution of LLM Agents Through Human-in-the-Loop Feedback

- Source: arXiv CS.AI
- Published: 2026-11-05
- Link: https://arxiv.org/abs/2608.15591
- Matched layers: ai_compute

Existing approaches address agent construction and one-time evaluation but provide no structured mechanism for continuous post-deployment behavioral correction without modifying the agent's source code. We introduce Agent Gym, a modular, domain-agnostic framework that wraps any existing LLM-based agent in a continuous evaluation-and-evolution loop.

### A latent control model for realistic rodent motion

- Source: arXiv CS.AI
- Published: 2026-11-05
- Link: https://arxiv.org/abs/2610.27279
- Matched layers: ai_compute

Here, we introduce Simulated Control via Augmented Motor Priors for Embodied Reinforcement learning (SCAMPER), a system for training an embodied virtual rat model, enabling natural movements during both goal-directed behavior and random exploration. SCAMPER uses a variational architecture with two distinct priors, a motion prior for control and a behavior prior for exploration.
